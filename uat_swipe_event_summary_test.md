# UAT Screen Test 1: Swipe Event Summary

## Purpose
This test is intended to evaluate the participant’s ability to use the **Swipe Event Summary** screen to:
- interact with the retractable filters
- apply a filter
- identify and select swipe event outliers
- view selected swipe events in the temporal frame view
- inspect a full swipe event
- select and highlight individual footsteps
- use the cumulative and individual step selector beneath the P100 image

## Starting Condition
- The application is running locally
- The participant has already completed the setup steps
- The dashboard is open in the browser
- The participant is on the **Swipe Event Summary** screen

## Participant Tasks

### Task 1: Interact with the retractable filters
- Locate the retractable or collapsible filter section on the Swipe Event Summary screen
- Expand the filters
- Review the available filtering options

### Task 2: Apply a filter
- Enter or select at least one filter value
- Apply the filter
- Confirm that the displayed swipe events update in response to the selected filter

### Task 3: Select swipe event outliers using the lasso tool
- Locate the scatter plot or main visualization showing swipe events
- Use the **lasso tool** to select one or more swipe event outliers
- Any visible outliers may be selected for the purposes of this test

### Task 4: View the selected swipe events in the temporal frame view
- After selecting swipe event outliers with the lasso tool, proceed to display those selected events in the **frame temporal view** below
- Confirm that the lower view updates to reflect the selected swipe events

### Task 5: Open and inspect a full swipe event
- Select one of the swipe events currently being displayed
- Open or inspect the **full swipe event** view
- Review the full event display

### Task 6: Select an individual footstep
- Within the full swipe event view, click on a specific footstep
- Confirm that the selected footstep is visually highlighted

### Task 7: Use the cumulative and individual step selector
- Locate the selector or control bar below the **P100 image**
- Use this control to interact with the step display
- Switch between:
  - cumulative step view
  - individual step view
- Confirm that the displayed content changes appropriately when the selection changes

## Success Criteria
The task is considered successful if the participant is able to:
- open and use the retractable filters
- apply a filter successfully
- use the lasso tool to select swipe event outliers
- load those selected swipe events into the temporal frame view
- inspect a full swipe event
- click and highlight a specific footstep
- use the selector below the P100 image to switch between cumulative and individual step views


## Completion Statement
This screen test is complete once the participant has successfully interacted with the filters, selected outlier swipe events, viewed them in the temporal frame view, inspected a full swipe event, selected a footstep, and used the cumulative/individual step selector beneath the P100 image.
