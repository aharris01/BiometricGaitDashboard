##Steps to Access the Cyber Center Dataset
#1. Connect to the Server (use UNB VPN)
- Open a terminal and run "ssh <username>@lambda.int.unb.ca"
- Enter the temporary password
#2. Change Password
- run "passwd" command to change password.
- Enter the old password once, then type new password twice.
#3. Dataset Access
- see content: "ls /home/cc-data/cc"
- move into: "cd /home/cc-data/cc"
- inspect file: "ls -lh"
- preview file: "head filename.txt"
