# UAT Screen Test 2: Footstep View

## Purpose
This test is intended to evaluate the participant’s ability to use the **Footstep View** screen to:
- switch from the Swipe Event Summary screen to the Footstep View screen
- interact with the retractable filters
- apply filters to display specific footsteps
- open a footstep review window from a thumbnail
- edit an existing footstep
- create a new footstep
- delete a footstep
- review the change log to confirm that those changes were recorded

## Starting Condition
- The application is running locally
- The participant has already completed the setup steps
- The dashboard is open in the browser
- The participant is currently on the main application interface

## Participant Tasks

### Task 1: Switch to Footstep View
- Locate the **Footstep View** button at the top of the application
- Select the button to change from the current screen to the Footstep View screen
- Confirm that the screen changes successfully

### Task 2: Interact with the retractable filters
- Locate the retractable or collapsible filter section on the Footstep View screen
- Expand the filters
- Review the available filtering options

### Task 3: Apply filters to show specific footsteps
- Enter or select one or more filter values
- Apply the filters
- Confirm that the displayed footstep results update in response to the selected filters

### Task 4: Open a footstep review window
- Locate the displayed footstep thumbnails
- Select one footstep thumbnail
- Confirm that the **review window** opens for that footstep

### Task 5: Edit an existing footstep
- In the review window, modify an existing footstep
- Save or confirm the edit
- Confirm that the change appears to have been applied successfully

### Task 6: Create a new footstep
- Use the available controls to create a new footstep
- Save or confirm the new step
- Confirm that the new footstep appears in the interface

### Task 7: Delete a footstep
- Delete either:
  - the newly created footstep, or
  - a different existing footstep
- Confirm that the selected footstep is removed successfully

### Task 8: Review the change log
- Locate and open the **change log**
- Review the recorded history
- Confirm that the edit, creation, and deletion actions appear in the log

## Success Criteria
The task is considered successful if the participant is able to:
- switch to the Footstep View screen
- open and use the retractable filters
- apply filters to display specific footsteps
- open the review window from a footstep thumbnail
- edit an existing footstep
- create a new footstep
- delete a footstep
- open the change log and verify that all changes were recorded

## Completion Statement
This screen test is complete once the participant has successfully switched to the Footstep View screen, used the filters, opened a footstep review window, edited a footstep, created a new footstep, deleted a footstep, and verified those actions in the change log.
